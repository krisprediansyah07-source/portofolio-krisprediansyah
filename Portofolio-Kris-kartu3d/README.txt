KARTU 3D NATIVE (HTML + CSS + JavaScript)

1. Salin folder ini ke dalam folder Portofolio-Kris atau pindahkan file/foldernya sesuai struktur.
2. Jangan hapus atau timpa index.html milik portofolio lama.
3. Buka folder Portofolio-Kris di Visual Studio Code.
4. Instal ekstensi Live Server bila belum ada.
5. Klik kanan kartu-3d.html lalu pilih Open with Live Server.
6. Halaman menggunakan Three.js dari CDN, jadi perlu koneksi internet saat dibuka.

Catatan:
- kartu-3d.html adalah halaman terpisah, sehingga tidak merusak halaman portofolio yang lama.
- Link kembali mengarah ke index.html. Jika nama halaman utama berbeda, sesuaikan href di kartu-3d.html.
- Gerakan kartu dan tali adalah pendekatan native yang meniru interaksi dasar. Simulasi fisika tidak identik 100% dengan versi React/Rapier.
